# 升级选择 UI：第一版素材与确认记录

状态：设计已更新；本轮仅生成原始素材，不加工、不切图、不入库、不修改运行界面。

## 已确认设计
- 参考用户图 #6 与 #7：三图标初始横向等间距位于线谱上（约屏幕高度 61%）；到位后，同一图标上移至卡框上部，卡框同步展开。全程只有三个实际图标，没有复制图标。参考卡框横向中心约 25%、50%、75%，纵向范围约 25%—70%，仅作为布局比例。
- 进入和离开采用非线性轨迹；金色线谱有灵动弯曲、起伏与跟随拖曳。停驻阅读时动作应轻缓。
- 线谱从框体后方穿过，信息区域保持清晰。小金色音符为独立装饰，与线谱分层，后续单独浮动。
- 图标使用现有配件的干净主体，不含底部遮罩、底板。
- 选择期间暂停战斗，UI 使用不受战斗暂停影响的时间。
- 选择后卡框逆向收起；选中图标沿曲线飞向当前 HUD 左上角武器图标；未选图标缩回入场尺寸并回到线谱，随线谱从右侧出画。
- 当前所有信息框默认蓝色，着色主要用于边框和装饰条，正文使用浅米白阅读底。
- 品质系统在 UI 更新完成后另行新增。本轮不实现品质、不生成整套品质框。后续规则：衍生配件统一红色；子弹有蓝色和金色。
- 满包后将进入替换流程；本轮该分支留空，不设计替换页面、不假定已领取、不提前播放收纳成功。

## 原始素材清单
1. 蓝色信息框：空白浅米白内底、蓝色边框和装饰条；不烘焙文字或配件图标。
2. 金色小音符：六个分离元素的原始素材板。后续处理时才拆为独立 Sprite，本轮保持整图。
3. 金色五线谱：五根直线的原始横向纹理，后续以网格或程序曲线变形实现起伏，而非把波浪路径烘焙为固定背景。

透明背景直接由生成 API 输出，不进行后期抠图。生成结果属于首版候选，尚未裁切、切片、九宫格设置、压缩、制作材质或导入 Assets。后续仍需验证边缘、尺寸与五线数量等可用性。

## 动效说明
音符静态素材与浮动动画分开；本轮不制作动画。框体以同一图标为视觉锚点展开/收起。非线性轨迹与缓动曲线后续在界面实现阶段调校。
