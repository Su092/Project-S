## 本版变化
- 框体底色和主要装饰统一浅米白/淡香槟色，削减对应颜色面积，仅在细边线、角部、小菱形饰件保留配色。正文阅读底保持浅米白空白。
- 五根金色谱线保留直线原始结构，加强浅金高光、金色面、琥珀暗边的层次；以后由程序曲线/变形网格做灵动起伏。
- 小金色音符继续使用第一版 APIMart 原图，不重新生成。
- 图标上移、框体同步展开和反向收起、选中图标曲线飞向左上武器图标、未选项随线谱向右退场的规则不变。
- 战斗暂停而 UI 动效继续；满包替换流程留空。
