# 升级 UI · 线谱第三版
生成渠道：APIMart，gpt-image-2，2K 档位。仅重新设计线谱，信息框沿用第二版，音符沿用第一版。

## 设计方向
- 用轻盈的流动金丝替代直硬金条，以浅 S 形展示灵动状态。
- 增强浅金亮芯、金色刻纹、琥珀细暗边的层次。
- 上下外缘加入疏密有序的卷曲饰纹，与信息框音乐装饰相呼应。
- 保持五根主线可辨，中央留出图标活动空间。
- 独立浮动的音符不烘焙进线谱；动效尚未实现。

## 当前信息框
绿色用于枪械；蓝色用于默认配件/蓝色子弹；金色用于金色子弹；红色用于衍生配件。白色、紫色不在当前方案内。
