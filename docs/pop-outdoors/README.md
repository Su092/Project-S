## 美术方向

图 16 用作日景标尺。暖杏色天空、珊瑚红土地，地面压低对比；墨紫小怪和浅色眼睛构成第一阅读层。图 15 用作夜景和首领战标尺。深紫地面与天空拉开明度，以洋红双圈预警、青色拾取物和浅色音弹建立第二阅读层。两种光照共用室外布局，并分别制作可对比的测试场景状态。

怪物用圆、楔、扇、短耳和肢体负空间区分。玩家有浅色领饰和乐器，敌人有实体深轮廓和清晰攻击器官。友弹用亮芯或短划，敌弹有外沿，危险区有扩张双圈和起爆节拍。颜色、轮廓、运动三者至少提供两种判断依据。以运动中的小尺寸效果定稿，避免人物眼睛、弹点和经验珠在远处看起来一样。

**资产制作。** 3D 网格、骨架、模型动作、LOD 和烘焙使用指定的 arjun988 Blender 工具集（`E:\Unity Development\.agents\skill\arjun988 blender`）。2D 插画、角色头像、HUD、图标、色彩图与天空全景使用 APIMart。法线、ORM、碰撞代理、导航等从实验模型和材质数据生成，保证通道与几何对应。每批保留可编辑源、导出件、入库映射和参考回执。

## 室外空间与天空盒

- **开场枢纽拟改为露天乐队营地。** 标题仍有随鼠标转动的音符。进入营地后，左侧立镜选角，右侧谱桌办理共享养成，桌上的老式唱片机保留醒目的大金属喇叭，正前方拱门带已选角色进入关卡。镜内显示对应的小怪物插画，保留左右切换、能力和乐器气泡。
- **战区拟改为露天音乐节场地。** 中央平场承接首领和地面弹幕，外圈为连续移动路线，侧台提供高差与跳跃捷径。室内楼板与顶棚拆分为观众台、坡地和遮阳构件；用远山、巨型管风树和倾斜旗杆帮助玩家辨向。装饰避开主战区视线与导航走廊。
- **天空盒做昼、夜两套。** APIMart 输出可环绕的 2:1 天空全景，在 Unity 生成天空材质；检查水平接缝、两极与地平线。远景雾、环境光、反射和主光随预设切换。现有 `FoundryArena.ApplyEnvironment` 与 `BackstageWorld` 使用纯色清屏，两处相机入口都要接到新天空；标题音符等独立渲染相机按合成需求配置。
- **地图交付包括可玩数据。** 保留玩家出生点、首领出生点、16 个普通敌人出生点和关卡事件接口。按新地形重建导航、移动与射线碰撞、软边界、地面攻击投射、高低层连接、小地图遮挡和摄像机阻挡层。聚光攻击在户外通过局部对比突出预警。

## 六名小怪物与两种视角

六名角色继续绑定原初始乐器。绯燕用双叉燕尾，青瓷用双瓷角，夜航用鼓腹与耳鳍，紫鸢用长耳卷尾，金雀用扇冠，松影用风箱褶腹。共用骨架规范、碰撞尺寸和基础动作，分别制作躯干剪影、前臂外观与头像。保留共享养成和四种局内专属乐器的获取途径。

| 项目 | 实施与验收 |
|---|---|
| FPS | 默认第一人称。制作左右爪、前臂、装备／收起、演奏与回位动作。双臂使用独立表现层及合适的近裁面和视野。正常演奏让手指或爪子接触乐器，冲刺、贴墙、抬头和低头时检查穿模与准星遮挡。 |
| TPS | 拟用 V 切换并在设置显示键位。越肩跟随，肩高按小怪物统一视线标尺设置；墙角扫球检测，受阻时收近，离墙后平滑回弹。显示全身和手上乐器，同步移动、跳跃、转身与演奏。 |
| 角色和持握 | 当前 `DressPlayer` 按高度把部分渲染器设为只投影。新模型改为显式全身、第一人称双臂和乐器表现组。十种乐器各有左右手挂点与握持动作；小提琴弓、大提琴弓、风箱、摇柄和双铃分别验收。 |
| 瞄准与发射 | 当前 `BeginCast` 从乐器口取位置、从相机取朝向。改为准星射线确定目标，再从世界演奏口指向该点，近距离另测遮挡；用同一份释放数据驱动两套表现。防止越肩绕掩体发射、切换时重新触发音弹、长光束在两个视角跳向不同目标。 |
| UI、镜子与存档 | 营地和关内均可测试两种视角；进入镜子、乐谱或菜单时由交互相机接管，退出恢复原模式。切换不重建角色、弹匣、谱面队列或养成数据。实验版单独保存视角偏好。 |

动作采用现有 Animator／轻量动画分层。Motion Matching 继续列在后续议题。

## 版本与回退

- `E:\S` 专用于 `main`。所有实验编辑、APIMart 输出、Blender 导出、Unity 导入和构建均从 `E:\S-pop-outdoors` 启动。旧导入器与工具中指向 `E:\S` 的绝对路径需在运行前改为当前工作区。
- 首次启动实验版前，在实验分支设置独立产品名、存档／遥测目录和 PlayerPrefs 命名空间。Unity 的 Library、Addressables 缓存、内容构建目录、Build 和截图各自归属所在工作区；回归使用独立测试存档。
- 每批只在实验分支提交，对照表记录验证结果。退回某个制作批次可在实验分支回退对应提交；体验当前稳定版本直接打开 `E:\S`。是否合并另行决定。
